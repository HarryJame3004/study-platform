# Study Web Application Specification

## Goal

Build a modern personal study interface that displays learning content stored in the repository.

The website is a presentation layer. The GitHub repository remains the source of truth for study content.

## Main Pages

### Home Dashboard

Should display:

- Continue Learning
- Today's lessons
- Subjects
- Recent lessons
- Study progress (future)

### Subject Page

Each subject should show:

- Subject information
- Available lessons
- Previous lessons
- Progress (future)

### Lesson Page

Each lesson should display:

- Title
- Learning objectives
- Main explanation
- Examples
- Exercises
- Flashcards
- Summary

## Requirements

- Mobile first
- Desktop support
- Dark mode
- Fast loading
- Data-driven content discovery
- No hard-coded subjects

## Future

Possible additions:

- Search
- Progress tracking
- Spaced repetition
- Notes
- PWA support
