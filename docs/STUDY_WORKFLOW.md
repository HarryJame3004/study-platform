# Study Workflow

## Learning Flow

```
Study with ChatGPT Web
        ↓
Understand the lesson
        ↓
Create lesson content
        ↓
Store in Study Platform
        ↓
Review with exercises and flashcards
```

## Content Structure

Each completed topic should become:

```
lesson.md
exercises.md
flashcards.md
```

## Current Subjects

- Computer Architecture
- C Programming
- Calculus
- Algebra
- Law and Data Protection
- Introduction to Programming

## Principle

Add learning content first. Build the website later.

The repository is the source of truth for personal study knowledge.
