# C Programming Journey

A structured roadmap for learning C programming from fundamentals to advanced topics.

## Roadmap

### Phase 0 — Programming Environment

- Introduction to C programming
- Compiler and build workflow
- Development environment
- Linux CLI and tools

### Phase 1 — C Fundamentals

- First C program
- Variables and data types
- Constants
- Basic syntax

### Phase 2 — Operators and Expressions

- Arithmetic operators
- Relational operators
- Logical operators
- Type conversion

### Phase 3 — Control Flow

- if / else
- switch
- for loop
- while loop
- do while loop

### Phase 4 — Functions

- Function declaration
- Parameters and return values
- Scope
- Function execution

### Phase 5 — Arrays and Strings

- One dimensional arrays
- Character arrays
- Strings
- Multi dimensional arrays

### Phase 6 — Pointers

- Addresses and pointers
- Dereference
- Pointer arithmetic
- Pointer and arrays
- Pointer and functions

### Phase 7 — Advanced C

- Function pointers
- Preprocessor
- Compilation and linking

### Phase 8 — Memory Management

- Stack and heap
- malloc/calloc/realloc/free
- Memory debugging

### Phase 9 — Professional Workflow

- Linux workflow
- Git and GitHub
- Project organization

## Learning Method

Each completed lesson will later be stored as:

- lesson.md
- exercises.md
- flashcards.md
